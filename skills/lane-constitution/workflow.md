# Workflow

## Start

If `SKILL.md` still has `<placeholders>` or you have no real `agents/<id>.md` yet: `skills/FILL-CONSTITUTION.md` only. Append to `progress.md`. Do not write application code until the constitution is filled.

After it is filled:

1. Read `PLAN.md` — **Handbook Cycle** (which stage?) + your named tasks. Do not Build if Design gate is open.
2. Read `skills/<your-lane>/SKILL.md`.
3. Read **one** `agents/*.md` matching your id.
4. Collision: local lease **and** open PRs (`handoffs/README.md`). Stop on overlap.
5. Implement only those paths. Write `handoffs/<your-name>-<id>-<slug>.md` on this branch (copy `handoffs/PR.example.md`). **Handbook evidence** required.
6. No servers, no commit unless the human asked. Do not merge to `main`.
7. Append `progress.md` (stage + rubric). Open/update the PR with that handoff in the body.
8. Release lease.
